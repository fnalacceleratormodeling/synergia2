## BPM Tracking

This example tracks a kicked bunch through a simplified Booster lattice
saving bunch beam positions at all 24 BPM locations.

* `bpm_trace.py` A script to generate bpm data in the file `bpmdata.h5`.
* `BPM_tracking.ipynb` A jupyter notebook thar reads and displays the BPM data.
* `booster-00000.json` The Booster lattice file
